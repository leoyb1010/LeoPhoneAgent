# LeoBot 私有分发与更新说明

状态：先行契约；生产源码随后集成。对应 A008、A062，兼顾 A061/A063 的本界面范围。

## 分发规则

- Leo 的现有 `leo:bundle:mac` 明确使用 `ZCODE_AUTO_UPDATE=0`，产品采用私有机群手动分发；本包不打开自动更新、不自动公开发布、不改变证书、版本、安装目录或用户数据。
- 更新入口由实际构建能力与产品形态共同决定：仅 production 形态且 `ZCODE_AUTO_UPDATE_ENABLED=true` 时展示检查更新入口及自动下载偏好。禁用构建不展示一个不会生效的自动更新开关。
- 设置页保留可搜索的更新说明位置，明确显示“手动分发”，提示使用受信分发渠道取得新版并在退出应用后覆盖安装；不声称现有公开仓库/下载链接是当前版本来源。
- 保留通用跨平台更新器源码，不按行数将其认定为死代码；以后显式启用自动更新能力的构建仍使用原有流程。`shared/env.ts` 注释与当前 Leo 打包命令一致。

## 更新说明对话框

- 复用现有 Radix `Dialog`，由组件负责模态语义与焦点范围，不再维护全局 Escape 监听或手写遮罩。
- 打开时聚焦顶部标题且不滚动到底；Tab 留在对话框内。明确确认或 Escape 关闭后才按现有方法标为已读，点击遮罩不关闭。
- 关闭时将焦点返回打开前仍存在的控件；版本列表区域独立滚动，确认按钮始终可达。
- 标题、按钮和说明使用现有中英文翻译。历史版本条目保持已发布原文，不改版本号/发行内容。
- 使用现有中性色前景与表面、共享按钮，避免主色上反白导致的不足对比。元数据不使用低对比的 subtle 文本。
- `prefers-reduced-motion` 下内容与遮罩不做缩放/位移动画；本界面不再使用旧自绘卡片/遮罩的动画 class，不扩展为全局皮肤清理。

## 所有者与边界

- 构建能力事实仍归 `shared/env.ts`；前端更新入口判断归 `lib/desktopUpdateMenu.ts`，设置页复用它；原生应用菜单按同一构建能力与产品形态决定是否展示更新入口。
- 更新说明开关状态归 `LeoWhatsNew`；已读状态继续使用 `leoReleaseNotes` 原有入口，不新增存储。
- 不更改更新器运行时、遥测、备份、数据库、缓存或其他发布脚本。

## 验收场景与证据

- 自动更新关闭的桌面构建显示手动分发说明；production 且能力开启的构建保留原有入口和偏好；Web 不显示桌面更新控件。
- 更新说明标题/版本/正文可读，键盘焦点不逃出弹窗，Escape 与确认各只记录一次已读，遮罩不记录已读。
- 本包按用户要求仅做源码检查和必要生产编译；不编写或运行测试、lint、UI/perf 或额外 CI，实际交互由用户自行确认。
