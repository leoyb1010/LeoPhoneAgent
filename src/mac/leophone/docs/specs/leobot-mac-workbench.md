# LeoBot Mac 工作台与本机 Agent（2026-11-14）

用户已批准当前聊天的 HTML 方案，首阶段实现新工作台、本机 Agent 选择与 HTML 编程交付。默认高级、简约、黑白灰与蓝色；保留明暗主题、项目身份、手机链路和原有工程能力。本阶段不替换运行时，不接入实验 Harness，不引入第二套任务状态。

## 工作流与所有者

1. 首页先显示目标与输入框，再显示 HTML/代码/研究起步项、最近任务；起步项只填入草稿，不自动发送/覆盖非空草稿。
2. 左栏突出任务、资料、自动化；搜索继续可达，插件管理下沉到更多/设置。资料复用现有第二大脑只读视图，不创建资料库副本。
3. 输入区直接选择 ZCode、Codex CLI、Claude Code。选择使用现有 Composer model selection 命令和 ACP provider 模型目录，禁止新建并行偏好或执行队列。默认名称显示 ZCode；供应商/模型高级入口继续保留。
4. 新草稿可选择可用的本机 Agent；存在会话后固定执行者。运行中不跨 Agent，用户可明确新建任务；模型目录加载、失败、CLI缺失必须能解释和重试，不能静默改 Agent。
5. Host 现有检测提供本机路径/适配器事实，安装不等于登录。CLI使用自己的认证与配置；不复制令牌，不静默npx安装。

```text
用户选择 → Composer唯一草稿所有者 → frozen Submission → 既有Host/CommandInbox → 所选运行时
桌面 continuous ← 同一owner与序号 → 手机 replayable（保持现有恢复协议）
```

## HTML 编程与交付

- 随产品内置 HTML 工作流 Skill：以用户目标生成真实文件，复用工具链；要求交互、响应式、预览和实际检查，不以模型自报替代验证。
- HTML文本/文件在现有 PreviewPane 中提供预览/源码切换、下载原文件和明确继续修改入口。复用现有文件读取及路径权限，不在 UI 直接调用Repo或文件系统。
- 单文件预览用无同源权限的 sandbox iframe；不暴露IPC/Node/生产凭据。默认阻断网络、导航、表单与弹窗；默认静态预览；用户明确运行交互时允许当前版本的内联脚本，内容变化即撤销脚本许可。Main阻断srcdoc自导航。相对资源/远程依赖明确受限，不伪装完整项目预览。
- 文件内容必须完整读取且在大小界限内才执行预览，分片/大文件/无权限/错误均保留源码与可读提示。下载必须是原始内容，不把HTML改扩展名冒充Office文件。
- 已有会话的“继续修改”只把明确文件/要求放入本任务草稿，由用户提交；保留用户手动修改。

## 验收

- 单测：Agent候选/默认恢复/会话锁定；起步项不覆盖草稿；HTML检测、完整性、CSP/隔离、预览/源码/下载。
- 真实浏览器/Electron：新建任务→选Agent→输入→实际任务状态；HTML文件打开→预览→点击交互→源码→下载→继续修改；失败/取消/CLI不可用与键盘恢复。
- 1440×900、1280×800、窄屏、明暗主题与reduced motion。关键操作可见、无遮挡、无全页横向溢出。
- 95分以上为设计目标，评审必须依据真实渲染，不能以自评分或编译通过冒充用户验收。
- 必须执行typecheck、lint、architecture及影响范围内测试。未执行/环境失败与代码失败分开记录。

## 生产预览载体补充

真实生产CSP禁止inline script，srcdoc/data会继承，不能在主窗口放宽它。桌面使用`IPlatformService.htmlPreview`创建一次性原生预览句柄，`leo-html:`独立文档响应携带自己的受限CSP。Main只维护有界、按窗口归属且会过期的原生视图记录（最多32份、每份1MiB、15分钟）；不持有任务/session状态、不落盘、不开放HTTP端口、不在URL写入内容。预览释放与窗口销毁清理记录；迟到create结果由renderer清理。

创建输入为完整HTML和当前版本的interactive布尔；Main验证可信主页面sender、类型/大小/字段；返回随机id和独立URL。释放只允许原窗口。默认静态，明确运行时只给iframe `allow-scripts`，无same-origin/Node/IPC/弹窗/下载权限。外部资源、网络、子frame、表单均由响应CSP禁止，Main阻断预览帧自导航。Web/旧preload只有静态srcdoc，不声称支持脚本运行。

## 本机Codex可用性

Codex CLI选择必须同时具备本机可执行文件与已就绪的ACP适配器（随包或已安装），否则目录标为不可用。取消历史`npx -y`自动下载安装兜底，不改动Claude token/登录链。Host检测显式解析随包Codex适配器，UI刷新只称刷新目录，不承诺认证成功。

## 消息文件链接入口

真实Codex ACP任务返回的HTML Markdown链接必须与产物卡片进入同一PreviewPane，不能沿用本机HTML默认打开浏览器guest的旧分支。沿用既有stat、scope、workspace身份与错误恢复；显式“浏览器打开”能力仍走原入口。回归覆盖正文文件按钮打开产物、卡片打开产物，以及真实Codex已完成任务的恢复与交互。
