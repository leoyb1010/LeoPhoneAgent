# leocodebox 2.0.1(2026-09-20)

2.0.0 装机后的三处硬伤,当天修。

- **顶栏按钮点不动**:macOS 隐藏标题栏 + BrowserView 的组合下,窗口顶部约 42px 收不到真实鼠标事件(实测用 CGEvent 点击,DOM 收不到 mousedown;42px 以下正常)。2.0.0 把整排导航放在了这一条里,所以「主控 / 设备 / 通道 / 设置 / ⌘K / 暗亮」全是摆设。现在顶条只放标题与状态,导航、⌘K、明暗移到左栏,左栏在所有页面常驻。
- **没模型也能开会话**:首启没登录任何供应商,开会话直接得到 pi 的英文报错。现在新会话面板在本机没有可用模型时给出提示和「去设置」按钮,「开始」不可点;pi 的报错翻成中文。
- **终端抽屉一开就退出**:抽屉以 plain shell 打开却没给命令,服务端跑了 `bash -c ""`。现在起交互登录 shell。

不是 leocodebox 的问题但容易混淆:Dock 上那个叫 "exec" 的图标是 Hermes 网关起的 `npm exec @upstash/context7-mcp`(父进程 hermes gateway),与本应用无关。
