# leocodebox 1.60.0 — 一轮真刀真枪的 review / debug + 化繁为简

这一版没有新功能,全是**查出来的真问题**和**删掉的多余东西**。所有缺陷都由独立审查复核过、并写了能复现原故障的回归测试。

## 安全(必读)
- **内核沙箱逃逸(已修)**:`write_file` 写一个**尚不存在**的路径时,符号链接从未被解析——根目录里只要有一个软链目录(workspace link、node_modules 链接,或你自己建的),`write_file("link/x.txt")` 就会写到根目录**外面**,`mkdir -p` 还能在外面造出整棵目录树。现在改为**向上找到最近的已存在祖先**再做 realpath 校验,并与**真实根**比较(根本身是软链也正确)。新增回归测试精确复现该场景。

## 修的缺陷
- **`run_shell` 会把请求永久挂住**:命令一旦后台化子进程(`npm run dev &`、`sleep 300 &`),`sh` 秒退但孙进程仍占着 stdio,`close` 永不触发 → `/kernel/run` 一直不返回,超时也形同虚设(只发信号给 `sh`)。改为按 `exit` + 短暂宽限返回,并让超时**杀整个进程组**。回归测试:原本永久挂起,现在 216ms 返回。
- **网关把 `/v1` 拼两遍**:节点地址若本身以 `/v1` 结尾(仓库明确支持这种写法),请求会打到 `/v1/v1/messages` → 404;404 不可重试,于是**不触发故障转移**、原样吐给 CLI,而健康探针却一直显示该节点正常。已按既有 `appendApiPath` 规则收敛并加单测。
- **计量在长回复上严重失真**:tee 副本只留头部 512KB,而 token 总数在 SSE 的**最后一条 `message_delta`** 里——长回复被记成约 1 个输出 token、成本近乎 0。改为**头部 + 尾部**双段保留。
- **客户端断开后仍在烧钱**:CLI 里 Ctrl-C 后,网关不中止上游、继续把整段生成拉完并计为成功的 200。现在 `req.close` → `AbortController` 中止上游并停止读取。
- **上游解析异常可能拖垮整个服务**:Express 4 不接管 async handler 的 Promise,`readStore()`(读盘 + 解密)一旦抛错就是未捕获拒绝 → 整个 app 退出。已加 try/catch,只失败这一个请求。
- **compaction 反而可能更贵(已修)**:裁剪边界原本每轮前移,导致**上一轮已原样发出的历史这一轮被改写**,前缀变化会击穿 prompt cache——一个降本功能在它最针对的长对话上反而多花钱。现在边界**按 20 条为一档量化**,前缀在多轮之间逐字节稳定(相应地,压缩从更长的对话才开始生效)。

## 体验修复(驾驶舱)
- **Claude 账号显示真实邮箱**:改从 Claude Code 自己的配置读取账号地址,不再显示占位英文 `Authenticated`(与 Codex 卡一致)。
- **清掉界面里的英文占位**:`Authenticated` / `Logged in` / `API Key Auth` / `xai credentials` 等散落在 4 个 provider 的字面量全部删除,改为返回 `null`,由前端既有的中文「已登录」兜底渲染——**是删代码,不是加翻译**。
- **一键安装不再静默失败**:409(该工具没有一键安装方式)带着好好的中文提示却被空 catch 吞掉;安装失败还会以 HTTP 200 + `success:false` 返回而被当成成功。现在两条路径都会把服务端的原因显示出来。
- **「重试」不再跳走**:Mission / 项目概览卡加载失败时的「重试」原本绑的是跳转到别的标签页,现在真的重新拉取。
- **运行中会话不再撒谎**:首次轮询失败(启动初期常见)原本渲染成「当前没有运行中的 Agent」;现在显示真实错误 + 重试。顺带把每秒 tick 改为**仅在真有会话时**运行且随窗口可见性暂停。
- **网关卡不再假装「已关闭」**:状态读不到时原本和「未开启」长得一模一样、开关点了没反应;现在明确显示读取失败并可重试。
- **Claude 窗口消耗不再显示假数据**:本机没有 Claude 用量时,原本会渲染出 0 token / 0 轮 / 「<当前时间> 重置」的一块,看起来像坏了或额度过期;现在直接不显示。
- **同一个数字不再两种写法**:今日成本原先在一处是 `¥1234.56`、另一处是 `¥1,235`,统一走同一个格式化(并补了 NaN 兜底)。

## 化繁为简(删掉的)
- 删掉驾驶舱里**点了没反应的「回收站」按钮**(从来没绑过点击,计数还读了接口根本不返回的字段)和**打开一坨 JSON 的「配置备份」链接**——这两件事在「设置 → 恢复」里本来就有。
- 删掉 `useDashboardData` 里**没有任何人读**的 running 切片:它还每 30 秒重复请求一次 RunningSessionsCard 已经在 5 秒轮询的同一个接口。
- 删掉与 `formatTokensCn` **一字不差**的重复函数、以及计算了却无人使用的 `initialLoading`。
- **经评估后特意没做**的一件事:合并两处 spawn/EBADF 重试助手。它们真正相同的只有约 10 行,而结果结构、并发闸(账号面板会被排到 28 个 CLI 探针后面)、Windows 上 `cross-spawn` 的差异、以及测试用的注入接缝都不同——合并是重写而非删除,还会踩回仓库里有明确注释记录的两个旧坑。**保持现状是更简的选择。**
