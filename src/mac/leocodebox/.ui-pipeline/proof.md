# leocodebox 2.0 UI proof

Mode: Operate · Level 1(原型→实现的首轮)。证据来自 vite + 隔离 LEOAGENT_HOME 的测试服务在内置浏览器里的真实渲染(1280×800)。

## 已渲染并交互过
- 主控:左栏按机器分组、筛选 chip(全部/进行中/需要你/失败/历史)、会话行(状态点 · 标题 · 模型 · 最后一件事 · 时间)。
- 会话:悬浮玻璃会话头(标题 + 机器 · 目录;模型 / 审批 / ⋯ chip)、运行流水(你 / 模型 / $ 工具 / 需要确认 / 系统行)、悬浮输入区。
- 审批卡:批准一次 / 本会话允许 / 拒绝 + 绑定说明;点批准 → 工具行「完成 · 展开」+ 系统行「已批准一次 · …」+ 模型收尾 + 左栏「已完成」。
- 新会话面板(机器 / 审批 / 模型 / 目录 / 第一句话)→ 创建即打开。
- 终端抽屉(xterm 连上,Starting terminal in cwd)、设备页、通道页(Telegram 状态 / 配对 / 已配对聊天)、设置页(41 家供应商,OAuth 登录按钮,更多设置入口)、亮色主题。
- 控制台:业务路径 0 错误;残留的 404/HMR 报错是 vite 对已删文件的陈旧模块图,重启 vite 即清。
