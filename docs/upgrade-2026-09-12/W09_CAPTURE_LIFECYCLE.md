# W09 录音权限等待与中断恢复

## 本轮修复

录音启动现在由一个有身份的权限等待请求持有。停止、关闭/重置面板、进入后台、切换语言或引擎、进入文字编辑、发送后停止都会取消该请求。迟到的权限成功或失败回调不能重新打开麦克风，也不能清除或替换后续请求。普通麦克风点击与编辑后的恢复共用同一个启动入口。权限准备期间有可见提示；麦克风或系统识别授权失败分别进入已有错误提示。

音频中断结束时，仅在系统允许自动恢复时重建引擎；不允许时把可转写的已捕获片段送入原有处理路径，然后停止。中断仍在进行时，路由变化不能提前重启录音。已经停止的录音也不会因路由事件复活。

[Apple 路由通知文档](https://developer.apple.com/documentation/avfaudio/avaudiosession/routechangenotification) 明确该通知在后台线程发送；原回调可能直接进入主线程音频协调器清理。本轮将路由恢复转到主线程，并在执行时重新检查当前录音和中断状态。[中断通知](https://developer.apple.com/documentation/avfaudio/avaudiosession/interruptionnotification) 本身由系统在主线程发送。
