# W04 日志持久化实现

2026-09-12：Mac 宿主接入 HarnessJournal。异步队列最多 2048 条、8 MiB，关键事件保留容量，批量追加后 fsync，关键通知只在提交回调中发出。失败和溢出记录 durable/persisted/latest 水位与缺失范围；实时事件标记 pending/unavailable，不谎报落盘。

历史回放使用有界 NDJSON 解码、稀疏索引和异步页迭代。启动历史恢复异步建立索引，HTTP 会话入口等待 ready。摘要边读边折叠，展示列表和正文缓冲有上限。重复序号不重复回放，损坏记录、重复序号、缺口会使完整收据不可用。收据先检查终态与持久性，未完成保存返回 JOURNAL_NOT_DURABLE。

订阅在回放前注册并保存 pending 快照，避免落盘与回放交接时漏帧；取消唤醒空闲订阅；慢 HTTP/SSE 连接等待 drain。journal_status=1 启用不含 seq 的持久性控制帧，旧客户端不需要识别新控制帧。Mac Fleet 转发该选项，控制台显示保存状态；iOS 源码增加同类状态和可见提示，控制帧不前移事件游标。

验证：Mac 446 项服务端测试通过；包含日志写失败、通知提交时序、队列洪峰、2 万行索引回放、损坏行、重复序号、终态订阅交接和断开取消。全量 TypeScript / lint 通过。iOS 最新逻辑测试及 generic iOS 设备目标构建通过；本轮新增 iOS 状态显示尚未覆盖安装到手机，之前的 1.35.0 (110) 安装证据不包含这项后续改动。

测试和报告不宣称磁盘硬件断电、所有跨设备长时间网络组合已验收；这些仍在全量计划中。Mac 1.85.0 发布产物与公证证据单独记录。
