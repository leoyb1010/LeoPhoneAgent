# LeoBot 数据流与隐私说明

更新：2026-11-10。适用本仓四端源码；具体构建能力、连接地址、权限与用户配置决定实际行为。本文描述实现边界，不表示所有历史审计项已修复。

## 谁会接收内容

| 使用场景 | 可能发送的内容 | 接收方 |
| --- | --- | --- |
| 模型对话与工具回合 | 输入、选定附件、会话上下文、工具参数和结果 | 当前配置的模型服务；外部工具还有自己的接收方 |
| Mac 配对远控 | 设备/会话标识、任务输入输出、审批与附件 | 用户配置的中继及目标 Mac；任务在对应运行时执行 |
| 第二大脑检索与阅读 | 检索词、资料标识、分页与设备鉴权信息 | 已配置的独立资料库/网关 |
| 第二大脑提问/摘要 | 问题、选定资料或资料引用、追问上下文 | 资料库服务；后续模型调用由该独立项目及配置控制 |
| 同步 | 会话、配置、被同步的资料及元数据 | 已启用的平台同步服务或用户配置的服务 |
| 推送 | 通知标识、任务状态；内容取决于推送设置与载荷 | Apple/Huawei 推送通路及设备 |
| 第三方登录/CLI/插件 | 所配置权限范围内的内容及工具输入输出 | 相应第三方提供商 |

第二大脑的原生设备 API 和网页登录不是同一权限凭据。设备只读令牌不能被解释为整个资料库登录权限；具体资料是否可供模型使用由服务端访问范围决定。本仓不保存服务端资料全集，也不替独立第二大脑项目承诺删除、保留或备份规则。

## 本机、同步与日志

会话、附件、浏览记录、CLI 环境、设置和诊断文件可以保存在设备或任务所在 Mac。各平台使用不同凭据机制，不能把它们统一理解为系统钥匙串或端到端加密。

iOS 现有 CloudKit 配置同步仍含 base64 包装的密钥/环境变量字段；base64 不是加密。相关实现见 [同步类型](../src/ios/Agent/Sync/V2/SyncedTypes.swift)。本轮依用户要求不改变存储、同步或备份策略，这一项保留为开放风险。

Mac 的底层运行时、第三方工具和网页有独立网络及持久化行为，详见 [桌面说明](../src/mac/leophone/NOTICE.md)。模型输入输出与故障日志可能包含原始文本、代码、路径及工具参数；已有脱敏不表示所有内容均已去敏。分享诊断材料应先选择接收范围。关闭窗口或移除一个连接不会自动清除已发送给第三方、其他设备、日志和既有备份的副本。

本轮保持原有数据目录、缓存、同步冲突、数据库与备份策略，不引入迁移。客户端取消等待不表示服务端任务已撤销，清空界面也不表示服务端数据已删除。

## 权限和分发

照片、麦克风、通知、位置、通讯录、日历、无障碍与桌面控制等能力受平台授权及对应产品配置约束。Agent 能执行的范围还取决于运行账号、工具、任务模式和已有授权；模型文本本身不能充当用户审批。

屏幕写操作、私有会话访问及外部文件入口的本轮修复以各平台源码与安装版本为准。main 可包含设备尚未安装的开发修改；源码审查或编译结果不能代替功能验收。
