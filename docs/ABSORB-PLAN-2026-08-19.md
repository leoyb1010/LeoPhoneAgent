## 1. 形态锁（先读这个）

**不动：**

- iPhone 默认仍是「此 iPhone 工作区」：本机 Agent + iSH + 藏宝阁 + Watch + 小组件
- Mac 仍是 1.73：打开能用、连接能力、被控、控制在线设备；退出即退出；不回托盘/额度
- Android 仍是独立端上 Agent；Power 特权不进 Standard
- 首页不改成仪表盘，设置不改成 Operit 那种市场+形象

**唯一形态延伸：**

- 已装本 App 的 Android，也成为和 Mac 一样的「身体」
- iPhone（以及 Mac 舰队页）指挥它，走**现有中继**，不新开遥控协议

**永远不做：**

整仓合 OpenMinis、抄 Operit、额度/托盘、iPhone 变纯节点、iOS 上 AutoGLM/ADB、没装本 App 的安卓、隔空打开 Power、GGUF 人格商店、Talk/Canvas、角色群聊。

## 3. 完整能力清单（合并三份扫描）

按「自用是否真能感到」排序。每条都写：来源、现状、补什么、不补什么、验收。

### A 档 · 身体与舰队（形态延伸 + 胶水）

#### A1. Android 成为身体

- **来源：** 你点名；协议已在（Hermex/OpenClaw 是驾驶舱，我们是「对面也是本 App」）
- **现状：** Android 能指挥 Mac，不能被指挥
- **补：** 出站注册（对偶 Mac relay-client）；harness `minis` 接 Android 本机 Agent；`platform=android`
- **不补：** 屏幕镜像、视觉点选、控没装本 App 的安卓
- **验收：** iPhone 列表出现在线 Fold8 → 发一句 → Fold8 会话真跑 → 杀 App 后变离线

#### A2. 机器列表改读中继

- **来源：** 上一版 P0 必要配套；OpenClaw/AionUi 都是发现式
- **现状：** iOS/Android 写死三台 Mac
- **补：** `/machines` 有什么显示什么；三台预设留作「一键填我的 Mac」快捷
- **验收：** 新 Android 上线后不用改仓库字符串

#### A3. 扫码加身体

- **来源：** Hermex、AionUi、OpenClaw、Enchanted
- **补：** 码内 = 中继根 + 机器名；钥匙不进码，用 iPhone 已有的
- **不补：** Bonjour 全网扫描、多网关公司
- **验收：** 新机器扫一下进列表

#### A4. 审批：App 没开也能响

- **来源：** OpenClaw push wake；我们自己的 CatchUp 注释
- **补：** 跑通已有 APNs 登记；通知只带 machine + approval_id
- **不补：** 自建推送公司、Voice Wake
- **验收：** 杀 iPhone App，Mac/Android 卡审批，锁屏通知能点进那张卡

### B 档 · 推理、模型、上下文（你点名要回来的）

#### B1. 推理强度补完（本版必写）

**现状不是「没有」，是「半套」：**

- iOS：会话里能调 `/thinking`，`ThinkingLevelCatalog` 用**硬编码前缀**卡上限（GPT-5.6 / Claude Opus / MiMo / Seed…）
- Mac：指挥条有推理芯片，按**当前 Agent** 列真实档，Codex 不会再给你选用不了的档
- 上游 1.12：可编辑思考规则、只显示该模型真支持的档、换模型时档位保留、Sol/Terra/Luna + Max/Ultra

**要补的三块：**

1. **可编辑规则（摘上游 ThinkingRule，挑文件）**  
   设置里一行一个模型家族：最高档、默认档。新模型不用改 Swift 硬编码。读不到官方档就写「未知，未发送」，不准默默降级。

2. **换模型保留档位**  
   你在 High，切到只支持到 Medium 的模型 → 夹到 Medium 并**看得见**；切回来恢复 High。上游 1.12 的「跨模型无缝保留」。

3. **远程带走**  
   iPhone 指挥 Mac / Android 时，第一条请求带上当前推理档。现在远程任务曾漏带 Agent（1.72 才修），档位很容易再漏一次。

**不补：** Operit 式「聊天/记忆/总结/UI 各一个模型」的四槽迷宫；不在首页做推理仪表盘。

**验收：**

- 选一个 catalog 里没有的新模型，能在设置里给它定最高档，发送值与档一致（抓包或日志）
- 从高档模型切到低档模型，芯片显示夹过，再切回高档恢复
- iPhone 设 High，派到 Mac Codex，Mac 会话实际是 Codex 允许的对应档，不是默认

#### B2. 读图委托

- **来源：** OpenMinis 1.12 Vision Group
- **补：** 非视觉模型把图交给指定视觉模型，回复写明「图是谁看的」
- **不补：** 自动乱点一个视觉模型、编一个百分比
- **验收：** 纯文本模型 + 一张图 → 回复里有委托说明；没配视觉模型 → 明说看不了

#### B3. 按用途选模型（瘦身版，不是 Operit 四槽）

只做三个用途，和现有分组兼容：

| 用途 | 默认 | 可改 |
|---|---|---|
| 对话 | 当前会话模型 | 已有 |
| 读图 | 空 = 不委托 | B2 |
| 压缩 / 标题 | 现有自动路径 | 可指定一个便宜模型 |

**不补：** UI 控制模型、记忆专用模型、密钥池 UI。

#### B4. 压缩看得见

- **来源：** 上游「Compact & Enable Auto-Compact」；我们引擎已有
- **补：** 对话里一个开关 + 一次「现在压缩」；压完有一条可见说明
- **不补：** 换压缩算法
- **验收：** 长会话能手动压；开关关掉后不再自动压

#### B5. 首包超时

- **来源：** 上游 1.12，30s → 120s
- **补：** 对账我们流式超时；慢中继 / 本地模型误杀就改到 120s
- **验收：** 对账记录写在 PR 里；该改的改，不该动的写明「已是 Xs」

#### B6. 供应商配置被静默清空

- **来源：** 上游 1.12 修读库失败丢配置
- **补：** 先对账 iOS `ProviderConfigStore` 失败路径；确认有坑再摘
- **验收：** 对账结论（有/无此坑）必须写明，禁止「顺便改一圈」

### C 档 · 日常好用（自用一周就能感到）

#### C1. 工具权限三档

- **来源：** Operit 默认「询问」
- **现状：** 敏感凭证已有允许一次 / 本会话 / 拒绝
- **补：** 把同一套语义铺到其余会改系统的工具（文件写、壳、浏览器 Cookie），默认询问
- **不补：** 每个工具一张设置页
- **验收：** 第一次写文件会问；选本会话后同会话不再问；拒绝则工具失败且说人话

#### C2. 会话列表「…」

- **来源：** 交接遗留；Maid/Operit 都有重命名删除
- **补：** 重命名 / 删除 / 归档，和项目抽屉 Sidebar 同一套语义
- **不补：** 用户文件夹（那是 C3）
- **验收：** 列表右侧能改名、删除、归档，项目抽屉里能看见同一结果

#### C3. 会话分组（可选，C2 之后）

- **来源：** 上游 1.12 文件夹卡片
- **补：** 用户建组、拖进去；自动归组默认关（自用先手动）
- **不补：** 首页改成 Operit 手风琴市场

#### C4. 会话导出 JSON / Markdown

- **来源：** Maid；我们 iOS 已有部分导出（1.6.x 分享卡/PDF）
- **补：** 对账缺的那一种（JSON 往返），缺再补
- **验收：** 导出再导入不丢消息

#### C5. 系列用语

- **来源：** 系列诊断
- **补：** 「新任务 / 本机 / 远程 / 进行中 / 审批」三端同一套词
- **不补：** 重做视觉系统
- **验收：** 对照表进仓库，三端截图用词一致

#### C6. Mac 主控台 UsageCenterCard

- **来源：** 1.73 删额度后的残留
- **补：** 改名叫「本机日志」或折进折叠，避免看成额度回魂
- **不补：** 把官方额度加回来

#### C7. iSH fork-guard

- **来源：** 上游推进 submodule
- **补：** 仅当沙盒崩过再跟；不当功能发版
- **验收：** 有崩溃日志才动

## 4. 和「推理强度」相关的跨端契约

派远程任务时一条请求必须带齐（1.72 已带 Agent，本方案补齐其余）：

```
agent / harness     已有（1.72）
cwd / machine       已有
first message       已有（1.73）
thinking / effort   B1，本方案补
permission mode     Mac 已有；iOS 派 Mac 时应对齐
```

Android `minis` harness：推理档映射到 Android 会话的 `ThinkingLevel`（或等价字段），没有的档就夹紧并回传「已夹到 X」。
