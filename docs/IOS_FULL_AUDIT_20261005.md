## 已确认修复

1. 首页附件、动作、语音、发送、停止与提示关闭按钮触区偏小，统一扩到 44 点并保留既有图标视觉。
2. 聊天麦克风只有触摸手势而无 VoiceOver 默认动作；增加无障碍激活，扩大触控圆，并保留拖出取消。
3. Paperclip 持久草稿、未知回执和已收起信息页的展开状态会长期停止轮询；改为仅真实编辑、提交或确认时暂停只读更新，草稿及请求编号保持不变。
4. Paperclip 工作区内收到本机会话链接后，只更新隐藏页面；有效会话、设置、新聊天及语音入口显式选择本机，冷启动已存在的设置目标也被消费。无效/保留会话 ID 不切换工作区。
5. 管理能力提供清晰的服务器网页交接入口，复用配置隔离的 Cookie 容器、HTTPS 同源限制和健康检查，关闭后重新核实会话。
