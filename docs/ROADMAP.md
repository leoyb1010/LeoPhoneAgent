# 当前升级顺序

更新：2026-11-10。来源为本轮审计与用户授权。

1. 统一主仓、保留遗留改动，先修审批、私有会话、网页及外部入口边界；原签名覆盖安装首批个人版本。
2. 第二大脑按已确认 API 优化检索、正文、分页、取消与连接配置，补齐 Mac/Android 真实只读入口；不复制资料库服务或私人凭据。
3. 按实际热点优化聊天读取、流式渲染、点按目标、减弱动态和真实界面文案；保持已有任务和数据所有者。
4. 每包独立提交、必要原生编译；最终统一版本/更新说明，按原签名补装真实设备并记录版本与源码。功能、界面和性能测试由用户完成。

备份、存储、数据库迁移、同步冲突策略、批量清理及测试建设按用户要求排除。按统计行数进行的巨型重写、自动公开发行、换签名、强行迁移服务和重写 Git 历史不作为快速修复替代品。架构拆分只在拥有明确调用契约及可控迁移边界时推进。

首批安装事实见根 README；未关闭项见本轮逐项台账。首批安装完成不代表整个审计已完成。
