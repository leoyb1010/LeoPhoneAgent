## 4. L1 结构与状态矩阵

- Mate XT2：单屏 sm、双屏 md、三屏 lg，分别记录**窗口总宽 vp**与截图。断点 600/840vp，不按像素值直接推断。官方三折叠像素宽度 1008/2048/3184 仅用于对应设备形态，不套用 Pura 开合参数。
- Pura X Max：外屏/内屏，各横竖屏；增加分屏窗口落在 599/600/839/840vp 附近的边界测试。
- 本机首页 lg 自动第三栏；sm 单栏，md 列表+对话。设置/模型/工作区走右侧原生栈，不整页丢掉原会话。
- 每档输入未发送文字和两张附件，选中一个会话，滚动至中间明确的一条消息；开合/旋转/弹出收起键盘后比对文字、附件、会话 ID 与该消息位置。
- lg 手动开关右栏 20 次，录屏；手动关闭后同一宽度/键盘变化不能自动重开，跨断点规则 350ms 稳定后应用，最近 1500ms 手动选择不能被反转。纯函数测试的 20 次不是此项的 UI 证据。
- 返回顺序：键盘 → 右栏 → 顶部 destination → 根会话/列表 → 桌面。工作区优先关闭预览/返回父目录；第二大脑优先退内部层级。边缘手势、系统返回、标题返回按钮都测。
- Web 从可控页面进入/退出：隐藏页面不得继续 browser automation；第二大脑隐藏/后台必须按原策略锁定。
- 远程机器/对话在折叠时保持同一 ChatPane；未发草稿不能丢。远程侧不凭空展示本机文件；远程工作区继续从真实“工作区”按钮进入。

文件：`L1/xt2-sm-*`、`xt2-md-*`、`xt2-lg-*`、`pura-outer-*`、`pura-inner-*`；保存前后对照和录屏，而非仅最终静态画面。

| 删除完整轮次 | 长按删除确认明确说明问答/工具一起删除；其他轮次、未发草稿、工作区文件不变 | 确认与结果 |
