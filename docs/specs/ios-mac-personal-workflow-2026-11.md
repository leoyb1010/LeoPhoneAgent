# LeoBot iOS / Mac 个人工作流升级

基线为 LeoBot main `dc2a382cd`。实施依据为 2026 年 11 月 24 日审核后的个人升级计划。

## iPhone 独立使用

- 已配置可用模型后直接进入手机首页。首次 Mac 配对可从设备入口主动发起。
- 首页和对话使用同一模型选择器。常用和最近可选单模型或分组。选择只影响当前草稿或既有会话，保存新对话默认是明确的独立操作。
- 手机草稿是正文、模型与附件的唯一所有者。选择附件和模型前后保留草稿，发送才建立运行业务会话。取消不清空草稿。
- 首页已有情境条承接本机待回答、未读、进行中和近期会话。待回答以会话和问题定位。入口不可用时展示原因和能执行的下一步。
- 常用配置直达默认模型、服务商、快捷任务和字号。沿用设置现有分类和搜索。通用服务商模板复用已有认证与模型目录。
- 应用字号默认使用系统 Dynamic Type，显式的应用字号继续覆写。Duo 外屏、展开及合折复用现有尺寸和保留区域策略，让输入和触控可达。
- iOS、Mac 共用蓝色强调与主按钮角色，普通成功用蓝或中性。告警与错误按原有含义显示。验收更新弹层、输入区、列表、选择器与设置的明暗外观。

## 预览与结果

- PDF、网页和本地 HTML 优先复用现有预览载体。收起保留当前会话、当前位置和产物身份。切换会话时不显示别的会话的预览回跳条。
- 同一次运行的结果以主机、会话、运行或结果事件身份去重，保留轻量引用，读取历史时不强制跳底。
- Mac Host 是已接单和任务进度的所有者。iOS 提交前保存草稿和请求意图，已接单后按主机独立更新快照，显示上次确认状态。网络失败优先核对已使用的请求身份。
- 审批响应和深链定位单条事项。手机缓存与发布状态保持保守，连接中与历史状态可辨认。
- 原有文件预览、会话、设备配对、自动化和资料库通过当前 API 继续工作。Apple / OpenMinis 参考行为需要转为 LeoBot 的现有技术栈与视觉规范。

## 验收

- iPhone 不配对 Mac，写一句、切模型、加 PDF、发送并回看。测试取消附件、无可用模型、固定快捷任务和大字号。
- Duo 合折、展开和键盘避让，检查模型面板、输入区、导航、阅读锚点和分享路由。明确区分模拟器与实机证据。
- Mac 首次打开、快速面板异步刷新、重复回执、HTML 预览与产物回跳。根据修改范围运行 iOS 与 Mac 的常规门禁。
- 私有覆盖安装保持账号、项目、会话与配对数据。安装目标为当前在线的 iPhone Duo，以及 Pro、Air、Studio、mini 的正式 Mac App。以构建校验、应用签名、回读版本和每台实际可证据为验收。
