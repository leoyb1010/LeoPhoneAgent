## 第二轮发现记录

第一轮部署产物 `audit-round1-candidate-20261005` 克隆为第二轮独立候选。重新覆盖全表领域；额外发现并修复：

1. 跨标签页账号切换尚未读取新会话时，旧 GET、旧 mutation 回调仍可能影响新账号；整体替换 QueryClient，隔离迟到成功、失败回滚和后续写入。未知提交继续保留旧账号草稿核实标记，不自动重发。协调标记不包含身份或凭据；发起标签关闭后，过期 pending 只能重新验证会话，不能恢复旧缓存。
2. Hermes 自检忽略 fatal stderr、配置覆盖运行身份字段；Grok JSON 错误在进程退出 0 时被忽略。修复成功判定与保留字段过滤。
3. 备份早期打开/写入拒绝导致进程未处理异常；缺失压缩输入错误未正确传播；损坏压缩备份可能已输出 SQL 后才报错。恢复先以有界内存生成私有完整验证快照，成功后才写数据库，退出清理临时文件。这不承诺任意 SQL 恢复都是原子事务。
4. 文件在首次 stat 后增长，原 readFile 超过预览字节上限。实际读取封顶 maxBytes + 1；超限明确拒绝。
5. 受限列表请求断开后继续扫描。增加请求存活信号，每批读取/授权后及下一批前检查；不取消其他调用方共享的全公司读取，不宣称正在执行的 SQL 被强制中止。
6. 模型目录精确 ID 回车无响应、无法用方向键进入选择、长 ID 重复截断。保持实际模型 ID，支持确认、键盘移动和更清晰的长名称。
